# Smplifai UI Test Automation Framework

## 📌 Project Overview

This project is an automated UI testing framework developed for the Smplifai web application.

The framework is designed to ensure application quality by automating end-to-end user scenarios, smoke tests, regression tests, and functional test cases.

---

## 🛠 Technologies Used

- Java 17
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Jenkins CI/CD
- Allure Report
- Git & GitHub
